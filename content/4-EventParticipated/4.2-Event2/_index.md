## Event Overview

Mini Meetup – First Cloud AI Journey was an event for sharing knowledge about Cloud, AWS, AI, security, DevOps, real-time systems, and career skills. The event included 6 presentations from different speakers, and each presentation focused on a specific topic.

Unlike an event that only focuses on one technical area, this meetup covered many different topics. Some presentations were suitable for beginners, such as Docker, while others were more technical, such as AWS WAF combined with Machine Learning, WebSocket for multiplayer games, and GraphRAG with Amazon Neptune. In addition, the event also included sharing sessions about teamwork and career development in the IT industry.

I found that this event helped participants have a broader view of how technology is used in real life, from packaging applications, protecting systems, and building real-time backends, to developing a career and working effectively in a team.

The main presentations in the event included:

* **Docker: A Containerization Technology** – an introduction to Docker and containerization technology
* **Combining AWS WAF with Machine Learning for Cyber Attack Detection** – combining AWS WAF with Machine Learning to detect cyber attacks
* **Multiplayer in the Cloud: Connecting Godot Clients with AWS WebSockets** – building a real-time multiplayer game with Godot and AWS WebSocket
* **The Art of Effective Teamwork** – sharing about how to work effectively in a team
* **From IT Helpdesk to Senior Sysadmin** – sharing a career journey from IT Helpdesk to Senior Sysadmin
* **AWS Neptune for Building a Graph Knowledge Base for GraphRAG** – introducing GraphRAG with Amazon Neptune and Amazon Bedrock

## Speakers And Main Topics

### 1. Bao Huynh – Docker: A Containerization Technology

This presentation introduced Docker from basic concepts to practical usage. The speaker started with the concept of virtual machines and their limitations, such as each virtual machine needing its own operating system, which can consume a lot of resources.

After that, the presentation introduced containerization as a lighter way to run applications. With Docker, an application and its required libraries can be packaged into a container. As a result, the application can run consistently in different environments such as a personal computer, server, CI/CD pipeline, or cloud environment.

The presentation also explained important Docker components such as Docker Image, Docker Container, Dockerfile, and common Docker commands.

### 2. Le Hoang Gia Dai – Combining AWS WAF with Machine Learning for Cyber Attack Detection

This was a technical presentation about system security. The speaker explained that rule-based AWS WAF can block many common attack types such as SQL Injection, XSS, bots, or brute force attacks.

However, rule-based WAF still has limitations, especially with new attack types such as zero-day attacks or hybrid attacks. Therefore, the presentation proposed combining AWS WAF with Machine Learning to detect cyber attacks based on behavior and real data.

The presentation mentioned the CSE-CIC-IDS2018 dataset, the LightGBM model, and an AWS architecture that included EC2, ALB, AWS WAF, Kinesis Data Firehose, Lambda, Security Hub, and GuardDuty.

### 3. Nguyen Quoc Bao – Multiplayer in the Cloud: Connecting Godot Clients with AWS WebSockets

This presentation shared how to build a real-time multiplayer game using Godot 4 and AWS services.

In this architecture, the Godot game client connects to API Gateway WebSocket. Lambda is used to process game logic such as matchmaking and the result of a Rock-Paper-Scissors game. DynamoDB is used to store the state of players and matches.

The presentation also mentioned real problems when building real-time systems, such as stale connections, GoneException errors, Lambda not storing state between invocations, and costs that can increase if DynamoDB Scan is used incorrectly.

### 4. Truong Huy Phuoc – The Art of Effective Teamwork

This presentation focused on teamwork skills and how to work effectively in a team.

Most slides in this presentation were images or infographics, so the full content could not be extracted completely by text extraction. However, from the summary, the presentation was related to work efficiency, team collaboration, teamwork rules, and supporting tools such as Trello, ClickUp, Google Workspace, Slack, and Discord.

The main lesson from this topic is that teamwork is very important in the technology industry. When working on real projects, being good at technical skills alone is not enough. We also need communication, task division, coordination, and mutual support.

### 5. Vinh Tran – From IT Helpdesk to Senior Sysadmin

This presentation shared a real career journey from IT Helpdesk to Senior Sysadmin, then expanded to Cloud and DevOps.

The speaker started from an IT Helpdesk position, then self-studied Linux and Networking, and gradually developed into a Sysadmin. After that, the speaker continued learning Cloud, Terraform, Docker, CI/CD, and DevOps mindset.

The meaningful point for me was that the presentation emphasized that the starting point does not decide the whole career. The important things are learning in the right direction, building real projects, creating a portfolio, and developing step by step with persistence.

### 6. Viet Phat – AWS Neptune for Building a Graph Knowledge Base for GraphRAG

This presentation introduced GraphRAG, which is an advanced approach compared to traditional RAG.

Traditional RAG usually depends heavily on vector search. This approach is useful, but it can be limited when a question requires reasoning through multiple relationship steps. GraphRAG solves this problem by using a graph database to store data as nodes and edges.

The presentation introduced Amazon Neptune as a graph database service from AWS. When combined with Amazon Bedrock Knowledge Bases or LlamaIndex, the system can build a knowledge base with clearer relationships, helping AI answer complex questions better.

## Important Terms

### Docker

Docker is a tool used to package applications into containers, helping applications run consistently in many different environments.

### Containerization

Containerization is a way to package an application together with its required libraries into a container.

### Docker Image

A Docker Image is a template used to create containers.

### Docker Container

A Docker Container is a running environment created from a Docker Image.

### Dockerfile

A Dockerfile is a file that describes the steps to build a Docker Image.

### AWS WAF

AWS WAF is a web application firewall service from AWS. It helps block dangerous requests such as SQL Injection, XSS, bots, or brute force attacks.

### NIDS

NIDS is a Network Intrusion Detection System used to monitor and detect attack behaviors.

### Machine Learning

Machine Learning is a technique that helps machines learn from data to detect patterns, classify information, or make predictions.

### LightGBM

LightGBM is a Machine Learning framework used to train models quickly and efficiently.

### WebSocket

WebSocket is a protocol that allows the client and server to communicate in both directions in real time.

### API Gateway WebSocket

API Gateway WebSocket is an AWS service used to create WebSocket APIs.

### Lambda

Lambda is a serverless service from AWS used to run code without managing servers.

### DynamoDB

DynamoDB is a NoSQL database service from AWS, often used to store data that needs fast access.

### GoneException

GoneException is an error that happens when the backend sends a message to a WebSocket connection that has already disconnected.

### RAG

RAG is a method that helps AI retrieve information from external data sources before answering.

### GraphRAG

GraphRAG is an advanced version of RAG that uses a graph database to store relationships between data.

### Amazon Neptune

Amazon Neptune is a graph database service from AWS.

### Amazon Bedrock

Amazon Bedrock is an AWS service used to access and use generative AI models.

### IT Helpdesk

IT Helpdesk is an IT position that provides technical support to users.

### Senior Sysadmin

Senior Sysadmin is a senior system administrator responsible for operating and managing complex infrastructure.

### DevOps

DevOps is a way of working that combines software development and system operations, usually focusing on automating build, test, and deployment processes.
