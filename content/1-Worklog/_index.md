**Week 1:** [Become familiar with the First Cloud AI Journey program, its members, and internship regulations; learn about the AWS Management Console, configure MFA and AWS Budgets, and practice with basic AWS services including Amazon EC2, Amazon RDS, AWS Lambda, and Amazon Bedrock.](1.1-week1/)

**Week 2:** [Study and practice fundamental AWS Networking concepts, including Amazon VPC, Public Subnets, Private Subnets, Route Tables, Internet Gateways, and NAT Gateways; deploy EC2 instances in different subnets and verify connectivity between network resources.](1.2-week2/)

**Week 3:** [Continue studying advanced AWS Networking solutions through Site-to-Site VPN, AWS Systems Manager Session Manager, VPC Endpoints, VPC Peering, Transit Gateway, and Route 53 Resolver Hybrid DNS; troubleshoot issues related to routing, Security Groups, IAM Roles, VPN connections, and DNS resolution.](1.3-week3/)

**Week 4:** [Study and practice AWS Compute services, including Amazon EC2, Amazon EBS, Snapshots, AMIs, User Data, and Instance Metadata; deploy application servers, manage storage volumes, create server images, and monitor resources using Amazon CloudWatch.](1.4-week4/)

**Week 5:** [Continue studying AWS Compute solutions and automate infrastructure deployment using AWS CloudFormation; practice with Elastic Load Balancing, Auto Scaling, Amazon EFS, Amazon FSx, and Amazon Lightsail, while troubleshooting configuration issues, service limits, and system scalability.](1.5-week5/)

**Week 6:** [Study and practice Amazon S3, including buckets, objects, storage classes, versioning, lifecycle policies, and content distribution through Amazon CloudFront; explore methods for storing, protecting, and optimizing data costs on AWS.](1.6-week6/)

**Week 7:** [Continue studying AWS Storage and Hybrid Cloud solutions, including AWS Backup, Amazon S3 Glacier, AWS Snow Family, VM Import/Export, and AWS Storage Gateway; practice backup, recovery, and data migration, while troubleshooting issues related to Storage Gateway, SMB, and IAM Roles.](1.7-week7/)

**Week 8:** [Study and practice AWS Security services, including IAM Users, IAM Roles, IAM Policies, Permission Boundaries, Amazon Cognito, AWS Organizations, IAM Identity Center, AWS KMS, and AWS Security Hub; apply the Least Privilege principle and troubleshoot issues related to access permissions, AssumeRole, and AWS CLI authentication using SSO.](1.8-week8/)

**Week 9:** [Study and practice AWS database services, including Amazon RDS, Amazon Aurora, Multi-AZ deployments, Read Replicas, Amazon Redshift, and Amazon ElastiCache; explore backup, recovery, performance monitoring, and database troubleshooting.](1.9-week9/)

**Week 10:** [Begin the AI AWS Architecture Reviewer Capstone Project; analyze requirements, define the MVP scope, design the serverless architecture and processing workflow, select Amazon S3, Amazon DynamoDB, AWS Step Functions, Amazon Bedrock, IAM, and Amazon CloudWatch, and assign responsibilities among team members.](1.10-week10/)

**Week 11:** [Complete the frontend and backend of the AI AWS Architecture Reviewer system; deploy the React frontend to Amazon S3 and Amazon CloudFront, configure Amazon API Gateway, the AWS Lambda Upload Service, the S3 Input Bucket, and Amazon DynamoDB, integrate upload and review features, track processing statuses, and test the flow from frontend to backend.](1.11-week11/)

**Week 12:** [Complete the entire Capstone Project by implementing the architecture diagram processing workflow using Amazon EventBridge, AWS Step Functions, the Lambda Diagram Extractor, and Amazon Bedrock; perform end-to-end testing, finalize project documentation and handover, summarize internship worklogs and progress, complete evaluation forms, obtain signatures and the official stamp, and conclude the internship.](1.12-week12/)
