**Tuần 1:** [Làm quen với chương trình First Cloud AI Journey, các thành viên và quy định trong quá trình thực tập; tìm hiểu AWS Management Console, thiết lập MFA, AWS Budgets và thực hành với các dịch vụ cơ bản gồm Amazon EC2, Amazon RDS, AWS Lambda và Amazon Bedrock.](1.1-week1/)

**Tuần 2:** [Tìm hiểu và thực hành các kiến thức AWS Networking cơ bản, bao gồm Amazon VPC, Public Subnet, Private Subnet, Route Table, Internet Gateway và NAT Gateway; đồng thời triển khai EC2 trong các subnet và kiểm tra kết nối giữa các tài nguyên mạng.](1.2-week2/)

**Tuần 3:** [Tiếp tục nghiên cứu AWS Networking nâng cao thông qua Site-to-Site VPN, AWS Systems Manager Session Manager, VPC Endpoint, VPC Peering, Transit Gateway và Route 53 Resolver Hybrid DNS; đồng thời xử lý các lỗi liên quan đến định tuyến, Security Group, IAM Role, VPN và phân giải DNS.](1.3-week3/)

**Tuần 4:** [Tìm hiểu và thực hành các dịch vụ AWS Compute gồm Amazon EC2, Amazon EBS, Snapshot, AMI, User Data và Instance Metadata; triển khai máy chủ ứng dụng, quản lý ổ đĩa, tạo bản sao máy chủ và theo dõi tài nguyên bằng Amazon CloudWatch.](1.4-week4/)

**Tuần 5:** [Tiếp tục nghiên cứu các giải pháp AWS Compute và triển khai hạ tầng tự động bằng AWS CloudFormation; thực hành Elastic Load Balancing, Auto Scaling, Amazon EFS, Amazon FSx và Amazon Lightsail, đồng thời xử lý các lỗi liên quan đến cấu hình, giới hạn tài nguyên và khả năng mở rộng hệ thống.](1.5-week5/)

**Tuần 6:** [Tìm hiểu và thực hành Amazon S3, bao gồm Bucket, Object, Storage Classes, Versioning, Lifecycle Policy và phân phối nội dung bằng Amazon CloudFront; đồng thời nghiên cứu các phương pháp lưu trữ, bảo vệ và tối ưu chi phí dữ liệu trên AWS.](1.6-week6/)

**Tuần 7:** [Tiếp tục nghiên cứu các giải pháp AWS Storage và Hybrid Cloud gồm AWS Backup, Amazon S3 Glacier, AWS Snow Family, VM Import/Export và AWS Storage Gateway; thực hành sao lưu, phục hồi, di chuyển dữ liệu và xử lý các lỗi liên quan đến Storage Gateway, SMB và IAM Role.](1.7-week7/)

**Tuần 8:** [Tìm hiểu và thực hành các dịch vụ AWS Security gồm IAM User, IAM Role, IAM Policy, Permission Boundary, Amazon Cognito, AWS Organizations, IAM Identity Center, AWS KMS và AWS Security Hub; áp dụng nguyên tắc Least Privilege và xử lý các lỗi liên quan đến quyền truy cập, Assume Role và xác thực AWS CLI bằng SSO.](1.8-week8/)

**Tuần 9:** [Tìm hiểu và thực hành các dịch vụ cơ sở dữ liệu trên AWS gồm Amazon RDS, Amazon Aurora, Multi-AZ Deployment, Read Replica, Amazon Redshift và Amazon ElastiCache; đồng thời nghiên cứu cơ chế backup, phục hồi, giám sát hiệu năng và xử lý sự cố cơ sở dữ liệu.](1.9-week9/)

**Tuần 10:** [Bắt đầu Capstone Project AI AWS Architecture Reviewer; tiến hành phân tích yêu cầu, xác định phạm vi MVP, thiết kế kiến trúc Serverless và workflow xử lý; lựa chọn các dịch vụ Amazon S3, Amazon DynamoDB, AWS Step Functions, Amazon Bedrock, IAM và Amazon CloudWatch, đồng thời phân chia nhiệm vụ giữa các thành viên trong nhóm.](1.10-week10/)

**Tuần 11:** [Hoàn thiện frontend và backend của hệ thống AI AWS Architecture Reviewer; triển khai React frontend lên Amazon S3 và Amazon CloudFront, cấu hình Amazon API Gateway, AWS Lambda Upload Service, S3 Input Bucket và Amazon DynamoDB; tích hợp chức năng upload, review, theo dõi trạng thái và kiểm thử luồng từ frontend đến backend.](1.11-week11/)

**Tuần 12:** [Hoàn thiện toàn bộ Capstone Project, triển khai workflow xử lý sơ đồ bằng Amazon EventBridge, AWS Step Functions, Lambda Diagram Extractor và Amazon Bedrock; kiểm thử end-to-end, hoàn thiện tài liệu và bàn giao project, đồng thời tổng hợp nhật ký, theo dõi tiến độ, hoàn thành các phiếu đánh giá, xin chữ ký, đóng dấu và kết thúc quá trình thực tập.](1.12-week12/)
